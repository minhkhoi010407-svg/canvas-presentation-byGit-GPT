# Design principles

- One slide should make one principal point; use an action title that expresses the point rather than naming a topic.
- Design from audience and evidence, not from a stock template or an arbitrary style prompt.
- Use a small, repeatable type and color system; maintain readable type, contrast, hierarchy, and whitespace.
- Prefer diagrams, charts, and images only when they clarify evidence or the story; do not use decorative visuals as substitutes for explanation.
- Label chart units, time ranges, denominators, and sources. Preserve numerical integrity when changing scales or visual encodings.
- Keep recurring elements consistent, while varying slide composition when the narrative warrants it.
- Test language density, glyph support, fonts, and line wrapping in the actual rendering environment.
- Provide alt text and non-color cues where supported; avoid conveying meaning by color alone.
- For image-first slides, minimize on-image text and inspect generated text carefully. For editable output, render/inspect the actual editable layout rather than assuming it resembles a reference image.
