# Presentation workflow

| Stage | Required input | Responsible capability | Output / gate |
|---|---|---|---|
| User brief | User request | Intake/orchestrator | audience, purpose, audience shift, format, language, constraints |
| Content research | Approved brief and open questions | Research agent/tools | source ledger; no unsupported factual claims |
| Fact verification | Draft claims and sources | Reviewer | checked claim records, dates, caveats, unresolved questions |
| Story architecture | Verified facts | Knowledge Cat or consulting specialist | narrative spine, section order, action-title outline |
| Art direction | Story and audience | Presentation Skill / visual director | design contract, typography, palette, layout grammar |
| Visual asset research | Design contract | Asset planner | licensed/user/generated asset plan with attribution and alt text |
| Storyboard | Outline and assets | Primary skill | slide-by-slide purpose, takeaway, evidence, content, visual, layout |
| Slide generation | Approved storyboard and slide model | Chosen adapter | renderer input and generated source files |
| Rendering | Renderer input, pinned runtime | Engine/framework | output plus environment details and render receipt |
| Visual QA | Rendered pages/contact sheet | Reviewer; Playwright only for browser paths | clipping, overlap, contrast, density, consistency findings |
| Content QA | Render, storyboard, evidence ledger | Independent reviewer | claim/citation/text checks and corrections |
| Editability QA | PPTX and requested editability contract | Office-compatible inspection | test edits on representative slides/elements |
| Export | QA-passed output | Delivery stage | requested formats, source artifacts, citations, limitations |

Do not advance on silent failure. Failed rendering, missing fonts, unavailable browser binaries, or unresolved factual claims must be surfaced in the run result and final delivery note.
