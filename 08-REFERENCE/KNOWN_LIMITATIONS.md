# Known limitations

- The toolkit contains no running application, API server, unified runtime, or real end-to-end output.
- Attached source archives do not embed Git revisions. The verified upstream tips are audit-time references, not source snapshot identifiers.
- Some sources are represented by selected documents/skills and others by reference notes. See `INTEGRATION_MANIFEST.md` for exact inclusion scope.
- Master Slide Skill's MIT license file contains an unresolved copyright-holder/year placeholder.
- OfficeGen was not attached as a ZIP; only selected metadata was verified from its exact upstream repository revision.
- The engine/framework matrix is conceptual. No adapters, package combinations, renderer binaries, generated PPTX files, or web app were tested here.
- Playwright checks browsers, not PPTX semantics or native editability. Browser screenshot QA alone cannot validate a PowerPoint deliverable.
- Rendering can differ across PowerPoint, LibreOffice, browser/PDF renderers, operating systems, and fonts.
- Asset/icon licenses do not grant rights to brands or third-party assets merely displayed by an upstream tool.
- A skill may prescribe APIs, command names, or optional scripts absent from this curated copy. Follow its source link when a referenced resource is not present.
- AI output needs human review for facts, source fidelity, typography, and image-generation artifacts.
